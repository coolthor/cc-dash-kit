# Assemble a personal dashboard

When the user says “根據這個 repo 的框架和我的使用習慣，幫我製作看板”, follow these steps. Work in a copy or fork of this repo. Do not install or enable it until the user asks.

1. **Detect locally.** Run `which nvidia-smi` and `df -h /`. Probe only `localhost` or `127.0.0.1` on ports 11434 (Ollama), 1234 (LM Studio), 8000 and 8080 with a three second timeout. A response means the service may be useful; ask before adding it. Do not scan a subnet or probe another host during detection.
2. **Ask exactly three questions, one at a time, and wait for each answer.** Use plain text questions so a terminal or Desktop user can answer directly: (a) What do you repeatedly check while working? (b) Do you delegate work to other AI systems? If yes, offer `pause-flag` and its read only `pause_status` tool, and tell the user to ask Claude to call it before dispatching. (c) Which machines or endpoints should appear, if any? Ask for display name and URL, never credentials. Treat an unanswered question as unanswered; ask it again before writing config.
3. **Choose from `src/sources/` first.** Default `quota` and `session` already work without configuration. Available opt ins are `gpu`, `disk`, `http-probe`, and `pause-flag`. Add a source file only when the library cannot express the request. Follow `{ id, detect($), sample($), card(data) }`; the `$` passed to sources is the scoped API adapter in `hooks/register.tsx`. Give every new source a parse test and a bounded sample. If detection fails, omit that card. A sample error stays on its own card.
4. **Write `dash.config.json`.** Use `dash.config.example.json` as a shape guide; use no keys, tokens, or passwords. `cards` is an ordered list. `path` must be absolute. `http-probe` needs an HTTP(S) URL. `pause-flag` needs an absolute path in an existing writable directory. Make the smallest useful version first. Run `claude plugin validate .` until it passes, then `claude plugin test .` and the parse/config tests. Show the initial dashboard to the user, then refine it from their criticism.
5. **Respect boundaries.** Never read conversation logs, transcripts, or history to infer preferences. Never write tokens or credentials to configuration. Never perform network scans in a hook. The pause query is advice for Claude, not a permission boundary. The button is the only UI control for the configured flag; it does not control external dispatch clients by itself.

Use `claude --plugin-dir "$PWD"` for a temporary trial only after the user requests loading it. The command `/cc-dash` opens the pane when automatic placement waits for more terminal width.
